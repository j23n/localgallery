# Exact pins for the model-pack build. Every one of these can move the bytes
# the pack ships, and the manifest hashes are what the app verifies, so they
# are pinned rather than bounded.
#
#   python3 -m venv .venv
#   .venv/bin/pip install -r requirements.txt
#
# CPU-only by construction: the macOS arm64 torch wheel on PyPI has no CUDA in
# it, and the build never touches a GPU (`torch.set_num_threads(1)`, CPU
# device). Total download is ~350 MB, dominated by torch.
#
# Verified on macOS 15 / arm64 / CPython 3.14. Older CPython works; the wheel
# tags below are the ones PyPI resolved for 3.14.
